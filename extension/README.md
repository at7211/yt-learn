yt-learn 擷取擴充功能（v1.8.0，未封裝）。
支援站點：YouTube 影片頁（https://www.youtube.com/watch?v=<id>）、Udemy 講座頁（https://www.udemy.com/course/<slug>/learn/lecture/<id>，課程 id 為 udemy.<lectureId>）、Netflix 播放頁（選擇性開啟，見下）、HelloInterview 課程頁（https://www.hellointerview.com/learn/…）與 Coursera 影片頁（https://www.coursera.org/learn/<slug>/lecture/<itemId>/<標題>，課程 id 為 coursera.<slug>.<itemId>）。五站共用同一個疊層引擎（overlay.js），站點差異都在 site.js 的轉接層（課程 id、播放器 {root, video}、廣告、隱藏原生字幕、換頁事件）。
載入：chrome://extensions → 開啟開發人員模式 → 載入未封裝項目 → 選此 extension/ 資料夾。改過檔案後按該擴充功能的「重新載入」，並重新整理 http://127.0.0.1:8765 的分頁。
入口一（圖示，疊層模式）：在 https://www.youtube.com/watch?v=<id> 分頁按工具列圖示 → 課程直接疊在 YouTube 播放器上（英文字幕＋當前單字橘色、繁中字幕、右側單字面板、開場 10 秒前情提要卡），再按一次關掉。這支還沒有課程時，播放器左下角出現小 pill「yt-learn：擷取字幕… → 產生課程 x% → 完成」，在目前分頁擷取字幕、等產課完成後自動疊上，不開新分頁。手動關掉後換片不會自動打開；開著時換到有課程的影片會自動疊上。
疊層快捷鍵（只在疊層開著時攔，輸入框內不攔；YouTube 自己的 Space、← →、F、C、K、J、L、M 不受影響）：Z 中文・E 英文・V 單字面板・R 重播本句・[ ] 上一句／下一句。
查字典：點字幕裡的任何一個字，影片暫停並在旁邊的小視窗開劍橋英漢字典（overlay.js 送 ytlearn:dict，worker 用 chrome.windows.create 開 520×760 popup，視窗 id 記在 storage.session 的 dictWindowId，之後的查詢沿用同一個視窗；只接受 https://dictionary.cambridge.org/ 的網址）。
疊層注意：看 yt-learn 課程時請把「沉浸式翻譯」在 YouTube 關掉（兩個疊層會疊在一起）。重新載入擴充功能後，已開著的 YouTube 分頁按圖示時 worker 會自動補注入 overlay.js，不必重新整理；只有注入也失敗時才退回舊行為（在目前分頁擷取 → 開新分頁 index.html?v=<id> 顯示進度）。Shorts／其他網址形式改用靜音背景分頁擷取。非影片頁 → 開 index.html。
Udemy 注意：只支援已購買課程的講座頁（不含預覽彈窗、Udemy Business 子網域），需要英文字幕。在講座頁按圖示 → 在目前分頁注入 vtt.js＋udemy-capture.js（isolated world），只重現頁面自己會做的兩個請求（講座 API、字幕 VTT），不批次、不背景；Udemy 非講座頁按圖示 → 開首頁。換課（SPA）由每秒輪詢偵測：課程 id 或播放器 {root, video} 任一改變都會拆掉重掛（Udemy 換課會整個換掉 <video>），自動換課只重新載入課程、不會自己開始擷取。worker 在點擊時凍結 {id, url}：/add 回來的 id 或擷取到的 videoId 不符就中止（「換課了，請回到原講座再試」）。疊層開著時隱藏 Udemy 自己的字幕（[class*="caption-container"]）。全螢幕下疊層是否仍在需人工確認。
Coursera 注意：只支援已登入、已註冊課程的影片頁，需要英文字幕。在影片頁按圖示 → 在目前分頁注入 vtt.js＋coursera-capture.js（isolated world）；字幕網址依序找 onDemandLectureVideos API（以 item id 查）、頁面的 <track>、靜音播放幾秒等 <track> 掛上（之後還原靜音、播放狀態與位置），不批次、不背景；Coursera 非影片頁按圖示 → 開首頁。換課（SPA）由每秒輪詢偵測。疊層開著時 ← → 也是上一句／下一句（取代 Coursera 播放器自己的左右鍵，關掉疊層就恢復；焦點在輸入框、滑桿或選單上時不攔；site.js 的 arrowsStepCues，其他站不受影響）。首頁與本機頁的行為同 Udemy：不在本機建課、不嵌播放器，連回影片頁並顯示單字複習格。
疊層手動驗收（自動化測不到）：在 chrome://extensions 重新載入未封裝的擴充功能、重新整理 YouTube 分頁後，按 F 進全螢幕確認字幕與面板仍在、尺寸跟著放大；劇院模式（T）與視窗縮放也看一次；長句英文會縮成兩行內。
Netflix（選擇性開啟，預設關閉）：Netflix 的字幕清單只在播放頁自己解開的 manifest 裡，所以需要一個在 MAIN world、document_start 包 JSON.parse 的唯讀 hook（netflix-hook.js + netflix-manifest.js）。它只讀 manifest 裡的字幕清單、不改請求、不發請求、不記錄網址、不寫 console；只有按圖示時才會抓字幕檔。開啟方式：在 https://www.netflix.com/watch/<id> 按圖示 → 開擴充自己的 netflix-enable.html → 按「啟用並重新載入這個分頁」→ 授權 https://www.netflix.com/* → worker 用 chrome.scripting.registerContentScripts 註冊hook（ytlearn-netflix-hook）與 overlay.js（ytlearn-netflix-overlay），再重新載入那個分頁（其它已開的 Netflix 分頁要自己重新整理）。也可以在圖示右鍵勾選「在 Netflix 啟用（開關後請重新整理頁面）」。意圖存在 chrome.storage.local.netflix = {desired, gen, cleanup}，worker 每次醒來都把權限與註冊對齊到意圖；在 chrome://extensions 收回網站權限會自動轉成關閉。啟用後在播放頁按圖示 → 和 YouTube／Udemy 一樣先交給疊層：第一次會在播放器左下角出現進度 pill（擷取字幕 → 產生課程 → 完成），課程做好後疊層自動蓋上（英文、繁中、單字欄、前情提要），之後再按圖示就是開／關疊層；Netflix 沒有本機播放模式，所以不會開本機播放器分頁；如果按的時候播放器還沒出現（疊層沒接手），會直接在分頁裡擷取，完成後再問一次疊層，仍找不到播放器就在圖示上顯示「找不到 Netflix 播放器，請重新整理頁面」。快捷鍵同 YouTube（Z 中文、E 英文、V 單字、R 重播本句、[ ] 上一句／下一句；Netflix 自己的 Space、←→、F、M、S、數字鍵照舊）。跳句一律透過 hook 呼叫播放器 API（ytlearn:nf-seek），絕不直接設 video.currentTime（Netflix 會報 M7375）。換集（網址變了）疊層會換成新一集的課程，沒有課程就收起來。診斷（probe：hook 統計、字幕軌與格式、抓一次英文字幕檔的 status／bytes／開頭、用播放器 API seek 到目前位置）不再由圖示觸發：在 Netflix 播放頁對圖示按右鍵 →「診斷目前的 Netflix 分頁」（開啟中 → 直接跑並打開 netflix-enable.html?tab=<id>#probe；關閉中 → 打開該分頁的啟用頁，顯示未啟用；不是播放頁 → 打開不帶分頁的啟用頁），或在帶 ?tab=<id> 的啟用頁按「診斷目前分頁」；結果顯示在 #probe（存 storage.session）。關閉：圖示右鍵取消勾選 → 寫入關閉、通知 Netflix 分頁（ytlearn:site-off）、註銷兩支腳本、最後撤回網站權限。關閉過程若被中斷，網站權限可能留著——無害（關閉狀態下 worker 一律拒絕 Netflix），再關一次即可。關閉狀態下 Netflix 的 lesson／job／build 訊息一律回 {disabled:true}。關閉後，已開著的 Netflix 分頁上的疊層與 pill 立刻消失，hook 收到 ytlearn:nf-off 後永久不再做事，該分頁按圖示也不會再擷取（要重新整理頁面）；進行中的擷取會在寫入前被擋下（/fail），不會寫進課程。限制：沒有英文字幕的片不行；廣告方案（有廣告的方案）尚未支援；Netflix 改版（播放頁 DOM、manifest 格式、播放器 API）可能讓 hook 或疊層失效；已經產好的課程不會自動改用之後抓到的官方繁中字幕，要刪掉那一課的 lesson 再重跑。
圖示右鍵選單：「打開 yt-learn 首頁」開 index.html，「設定」開 index.html#settings（首頁的設定區會自動展開），「在 Netflix 啟用」是勾選框（見上），「診斷目前的 Netflix 分頁」跑 probe（見上）；選單在 onInstalled 建立，重新載入擴充功能後才出現。
HelloInterview 注意：只支援 www.hellointerview.com/learn/ 底下有影片的課程頁，需要影片自帶的英文字幕軌。在課程頁按圖示 → 在目前分頁注入 vtt.js＋hellointerview-capture.js（isolated world），只讀 <track> 一次、只做一次 fetch；換頁（SPA）靠輪詢＋popstate 偵測，簽名網址（會過期）不存進課程。
入口二（本機首頁）：bridge.js 轉送頁面的 window.postMessage({type:'ytlearn:ping'|'ytlearn:capture', videoId})；回 ytlearn:ack 與 ytlearn:status。
除錯：在擴充功能頁點「service worker」開 console，看 [yt-learn] 日誌。
檔案：background.js（worker）、capture.js（MAIN world 擷取，與 bookmarklet.js 同源）、bridge.js（首頁 content script）、overlay.js（youtube.com／udemy.com／netflix.com／hellointerview.com／coursera.org 的疊層引擎 content script，全部用 createElement 建 DOM，因為 YouTube 強制 Trusted Types）、site.js（站點轉接層；Netflix 的 seek 走 hook）、overlay-state.js（疊層的純函式狀態）、vtt.js／udemy-capture.js（Udemy 字幕解析與擷取）、hellointerview-capture.js（HelloInterview 擷取，isolated world）、coursera-capture.js（Coursera 擷取，isolated world）、overlay.css（疊層樣式，抄自 web/style.css 的舞台段落）、timing.js／intro.js／dict.js（web/ 的逐字節複本，改一邊請同步另一邊）、ytid.js（網址解析，與 pipeline/jobs.py 同表）、netflix-manifest.js（Netflix manifest 摘要、挑軌、兩個 world 共用的訊息 validator）、netflix-hook.js（MAIN world 唯讀 hook，動態註冊）、ttml.js（Netflix TTML 封閉子集解析器，不支援的結構一律拒絕）、netflix-capture.js（isolated world；正式擷取與 probe）、netflix-enable.html／netflix-enable.js（啟用頁與診斷結果）。
