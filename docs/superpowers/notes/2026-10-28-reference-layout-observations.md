# 參考影片版面觀察（MJ English，pMJ8j8MioIE）

來源：2026-10-28 用 Chrome 擴充直接開影片，暫停在 0:25 與 1:00 兩格截圖（1456×819，畫面佔滿播放器）。擴充在抓第 3、4 格前斷線，0:04、0:14、5:00、9:32 尚未看到。另參考使用者提供的 0:24 截圖（2000×1020）量測。

## 影片畫面
- 影片本身是**滿版 16:9**，沒有縮小、沒有黑邊；主體（發言者）在左半邊。
- 右側蓋一層橫向深色漸層：約從畫面寬 48–50% 開始轉暗、57% 以後明顯、72% 以後接近全黑（使用者截圖量測：50–70% 區間亮度 34–61，72% 以後 ≈9）。能清楚辨識的畫面寬度約 70%，這就是「畫面靠左、約 70%」的來源。
- 兩格都是同一機位，無法判斷原片是否有放大位移。

## 底部霧化
- 字幕區背後有一層由透明轉深的縱向漸層，約從 60% 高度開始、底部最深（使用者截圖量測：左側亮度從 51% 高度的 228 降到 78% 的 47、98% 的 8）。
- 0:25 那格字幕後方的白襯衫看起來柔化；但名牌「SEN. MULLIN」在兩格都清楚可讀。判斷：深色漸層為主，若有 blur 也很輕。

## 字幕
- 底部置中、橫跨全寬，疊在畫面下緣之上（人物胸口），靠霧化層保證可讀。
- 英文：粗體襯線字、白色，精選字蜜桃橘；中文：金色襯線，下一行。

## 單字面板（右側）
- 文字區約 x 57–97%，坐在右側漸層的黑區上。標題列「── 本集精選 106 個字 …… 1 / 106」，計數在最右。
- 0:25（1/106）：只看到當前字＋後兩字，當前列「percentage n. / 百分比、比例 /pərˈsentɪdʒ/」為橘色、有淡色底框。右側「×1」與圓點。
- 1:00（7/106）：五列。已出現過的字（partisan、wage、average）用薄荷綠，尚未出現的（subtract、union dues）用白色；沒有橘色列，字幕也沒橘字——推測橘色只在該字正被唸到的瞬間出現。
- 0:25 的「1 / 106」外有一個手繪感的橘色橢圓圈，應是第一個字出現時的強調動畫。

## 左上角「前情提要」卡
- 0:25 有、1:00 沒有 → 只在影片前段出現一陣子，之後消失。確切出現與消失時間待補。
- 位置 x 4–19%、y 5–27%，疊在影片上。結構：綠色、字距很大的小眉標「前情提要」→ 粗體主標兩行（日期＋場合）→ 細橫線 → 兩行補充（誰質詢、誰作證），人名綠色強調。

## 對本專案的含意
- commit a437ce4 的「影片縮到 60% 貼左上、下方黑帶放字幕」**偏離參考**。參考是滿版畫面＋右側漸層＋底部霧化。
- 兩種做法待使用者決定：
  - A. 滿版 iframe＋右側漸層（約 48%→72% 轉黑）＋底部霧化漸層：最像參考；投影片類影片右側約 30% 會被蓋住。
  - B. iframe 寬 70% 靠左、垂直置中（上下留黑邊）＋底部霧化：畫面不被遮，但上下有黑邊、不像參考。
