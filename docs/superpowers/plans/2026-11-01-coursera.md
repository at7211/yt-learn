# yt-learn：Coursera 影片頁的雙語字幕疊層（第四個站點轉接層）

沿用 Udemy 立下的做法（`pipeline/ids.py` 的 id、`extension/site.js` 的轉接層、isolated world 擷取、`vtt.js`），引擎本身只多一個 adapter 旗標。

## 已驗證事實（2026-11-01，在使用者登入的 Chrome 上實測）

- 影片頁網址 `https://www.coursera.org/learn/<slug>/lecture/<itemId>/<標題>`，例如 `/learn/develop-generative-ai-applications-get-started/lecture/rV80m/introduction-to-in-context-learning`。
- 頁面的 `<h1>` 是這支影片的標題；字幕是 WebVTT、整句時間、無逐字時間。一支 344 秒的影片：94 句 → 78 cues、42 單字，38 秒完成，疊層與字幕正常顯示。

## 未驗證

- 真實頁面上字幕走的是 API 還是 `<track>`、`findPlayer` 走的是 `.video-js` 還是尺寸退回路徑，都沒有記錄；`.video-js` 與 `.vjs-*` 是依 video.js 的慣例寫的，模擬頁也照這個結構。
- 全螢幕時疊層是否留在畫面上、換課時 Coursera 是否沿用同一個 `<video>`。

## 設計決定

1. **id**：`coursera.<slug>.<itemId>`。item id 只在課程內有意義（Coursera 自己的 API key 是 `<courseId>~<itemId>`），所以 slug 要算進 id；點號不在 YouTube id 字元集內，不會碰撞，檔名也安全。長度上限 slug 120、item 32，避免檔名過長。三端（`pipeline/ids.py`、`web/ytid.js`、`extension/ytid.js`）與 `lessonIdFromUrl` 都用 `tests/fixtures/lesson_ids.json` 檢查。
2. **sourceUrl**：同 Udemy，必須是 Coursera 影片頁網址，且 slug 與 item id 都要和 videoId 一致。
3. **擷取**（`extension/coursera-capture.js`，isolated world，與 Udemy 同）：只取英文字幕，沒有就明確報錯。字幕網址依序找：`onDemandCourses.v1` + `onDemandLectureVideos.v1`（以 item id 查；每個請求最多 5 秒，掛住也留時間給後面）→ 頁面的 `<track>`（開始播放才掛上；SPA 換課當下可能還是上一講的，所以排在 API 後面）→ 靜音播放幾秒等 `<track>` 掛上。只有原本暫停的影片才會被播放，結束後還原靜音、暫停與播放位置；使用者正在看的影片不動。沒有 srclang 的 `<track>` 視為課程本身語言，排在標 `en` 的之後。`kind` 記 `unknown`（頁面看不出字幕是人工或自動）。
4. **轉接層**：`findPlayer` 以 `.video-js` 為 root；沒有時退回「與影片同尺寸的最外層祖先」並按 `<video>` 記住結果（引擎比對 root 身分，版面一變就重掛的話全螢幕會出事）。`nativeCaptionCss` 藏 `.vjs-text-track-display` 與 `video::cue`，並把 `.vjs-control-bar` 的 z-index 拉到疊層之上。沒有換頁事件，靠引擎每秒輪詢。
5. **← →**：adapter 新增選用旗標 `arrowsStepCues`，Coursera 開啟後開著疊層時 ← → 等同 `[ ]`，與本機播放器一致；YouTube、Udemy、Netflix 不變。輸入框內、焦點在滑桿／選單／分頁列（ARIA role）上、有修飾鍵、按住連發都不攔，關掉疊層就還原。
6. **本機頁**：同 Udemy，不在本機建課、不嵌播放器，顯示提示與驗證過的連結。

## 驗證

- `uv run --with pytest pytest -q`、`node --test tests/web/`。
- 擴充功能端到端：用 Chrome for Testing 載入 `extension/`，`--host-resolver-rules` 把 `www.coursera.org` 指到本機模擬頁，走真的 worker、`server.py` 與 `pipeline.build`，涵蓋字幕三條路徑、換課、左右鍵、開關疊層、無英文字幕、本機頁。腳本不進 repo。
- 真實頁面：見 PR 的測試說明。

## v1 不做

課程預覽、未註冊課程、測驗與閱讀項目、企業版路徑（`/programs/...`）、非英文字幕的課。

## 風險

- `onDemandLectureVideos.v1` 沒有官方文件，欄位名來自開源專案；壞了會退回 `<track>` 與靜音播放。
- `.vjs-*` 是 video.js 的公開 class；Coursera 換播放器時，壞的是隱藏原生字幕與控制列層級，疊層本身不受影響。
